# Guess the Number

A small terminal game: you start from a seed number and use arithmetic
operations (`+ - * /`) to reach a hidden target between 1 and 1000.
After every move you get a hint (Freezing → Blazing hot).

## Requirements
- Python 3.10+ (uses no external libraries)

## Run
```bash
python main.py
```

## How to play
1. Choose `1` and enter a starting number (1–1000).
2. Enter operations like `+ 25`, `*2`, `/ 4`, `- 10.5`.
3. Reach the secret number in as few moves as possible.
4. Type `exit` during a game to abandon it.
